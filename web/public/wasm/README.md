# WASM Binaries

This directory contains the compiled WebAssembly artifacts.

## Files

- `av2-parser.js` - Emscripten JavaScript glue code
- `av2-parser.wasm` - Compiled WebAssembly binary

## How to Generate

These files are generated during the WASM build process. See [WEB_TOOL.md](../../../WEB_TOOL.md) for more details.
